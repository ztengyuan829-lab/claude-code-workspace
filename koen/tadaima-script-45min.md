# 講演 読み原稿（45分・完全版）

## 「ただいま」と言える場所が、人を育てる。
### 〜元・児童養護施設の職員が見てきた、人が変わる瞬間〜

合同会社 Bloom Terra ／ NAOMI ATSUTA

> **使い方**
> このまま読めば45分です（1分＝約300字で計算）。質疑は別に15分。
> 【　】は、あなたの実際の数字・事例に差し替えるところ。
> ［　］は、話さない指示（間・スライド・動き）。
> 太字は、そこだけゆっくり、一段低い声で。聞き手がメモを取る合図になります。

---

## ０．つかみ（0〜5分）

［スライド１：タイトルのみ。しばらく何も言わずに客席を見る］

皆さん、こんにちは。【NAOMI ATSUTA】と申します。今日はお招きいただき、ありがとうございます。

今日は、人の育て方の話をしに来ました。

ただ、最初にお断りしておきます。
私は、経営の専門家ではありません。教育学の研究者でもありません。
マネジメントの理論を教えに来たわけでもないんです。

私がいたのは、児童養護施設です。【◯年間】、そこで働いていました。

［間］

児童養護施設というのは、さまざまな事情があって、親御さんと一緒に暮らせない子どもたちが生活している場所です。
私はそこで、子どもたちの毎日のそばにいました。

ごはんの時間。おやすみの前の、少しの雑談。
行ってらっしゃい、と言って送り出す朝。

特別なことは、何もしていません。毎日、それだけです。

［間］

さて、ここでひとつ、皆さんにお伝えしたいことがあります。

施設にいる子どもたちは、**大人にものすごくたくさん教えられてきた子どもたち**なんです。

挨拶の仕方も、片づけの仕方も、何度も何度も教わっている。
叱られた回数も、実は褒められた回数も、普通のご家庭の何倍もある。
関わってくれる大人の数だって、圧倒的に多いんです。

［少し前に出る］

それでも、変わらない子がいました。

私はずっと、自分の関わり方が下手なんだと思っていました。
もっと良い声のかけ方があるはずだ。もっと良い仕組みがあるはずだ。
本を読んで、研修に行って、記録を細かくつけて、会議で話し合って。

その子が変わったのは、私が上手な言葉を見つけた日ではありませんでした。

【◯か月】、経ったころです。
学校から帰ってきたその子に、私が台所から「おかえり」と言った。
その子が、小さい声で「ただいま」と返した。

それだけの日が、何十回か続いたあとでした。

［間を長く］

今日お話ししたいのは、たったこれだけのことです。

**人は、教えられて変わるのではありません。戻ってこられる場所ができたときに、変わります。**

そしてこれは、施設の子どもだけの話ではないんです。
皆さんの部下も、お子さんも、そして——今日ここに座っている皆さん自身も、まったく同じです。

45分、お付き合いください。

## １．なぜ、正しい関わりをしても人は変わらないのか（5〜13分）

［スライド２：「正しい関わり」を並べる］

まず、私の失敗の話からさせてください。

児童養護施設というところには、実は「やり方」がきちんと揃っています。
個別支援計画があります。毎日の記録があります。ケース会議があります。
心理士の先生もいます。研修もあります。

つまり、**道具はあるんです。**

私は、その道具を増やし続けました。
うまくいかないのは、自分の引き出しが少ないからだと思っていたので。

声かけのバリエーションを増やしました。
褒め方の本も読みました。
その子のために、特別な時間もつくりました。

［間］

結果、どうなったか。

**私が疲れました。**

そして、子どもは変わりませんでした。

［客席を見渡す］

……これ、聞き覚えのある方、いらっしゃいませんか。

職場でも、まったく同じことが起きていると思うんです。

1on1を導入した。フィードバックの研修も受けた。
褒め方の本も読んだ。評価制度も新しくした。
面談の回数も増やした。

**道具は増えたのに、人が育った実感だけがない。**

ご家庭でも同じです。
叱り方の本も読んだ。褒めて伸ばすのもやってみた。話を聞く時間もつくった。
それでも、子どもは変わらない。

［スライド３：「なぜか」の一行］

なぜか。

理由は、実は単純でした。

**相手がまだ、そこを「安心して失敗できる場所」だと思っていないからです。**

安心していない人に、正しい助言は届きません。
届かないどころか、刺さります。

正しければ正しいほど、痛いんです。

［間］

ここで、ひとつだけ皆さんに質問させてください。挙手でお答えください。

**皆さんの部下が、あなたに最初に報告してくるのは、うまくいった話ですか。それとも、失敗した話ですか。**

［実際に手を挙げてもらう。5秒待つ］

ありがとうございます。

これ、どちらが良い悪いという話ではないんです。ただ、**失敗の話が先に来る関係かどうか**。
今日これからお話しすることの、全部の土台がここにあります。

子どもも、まったく同じでした。
本当に助けが必要なことほど、最後まで言わないんです。
言ったら、また指導が始まるから。

## ２．見えている行動の下に、見えない土壌がある（13〜22分）

［スライド４：この一枚が講演の背骨。ゆっくり読み上げる］

```
   支援と子育ての現場で見てきたこと

     「教える」       と   「迎える」
     「できるようになる」 と   「戻ってこられる」
     「行動と成果」     と   「安心・関係・時間」
     「その子の課題」    と   「その子がいる場所」
```

［一つずつ指しながら、間を取って読む］

私たちは、ふだんどちらの話をしているでしょうか。

会議も、面談も、家庭の心配ごとも、ほとんどが**左側**なんです。

「あの子は集中力が続かない」
「彼は報告が遅い」
「あの人は主体性がない」

全部、左側です。

［間］

でも、私が【◯年】かけて分かったのは、こういうことでした。

**左側は、結果です。**

木にたとえると、左側は、土から上に出ている部分でしかない。
枝ぶりと、葉っぱと、実。目に見えるところです。

私たちは、その枝ぶりを一生懸命に直そうとします。
曲がっているから、まっすぐにしよう。葉が落ちているから、水をかけよう。

でも、**土が痩せている木の枝を直しても、またすぐ同じ形に戻ります。**

［スライド５：木の絵。上が「行動」、下が「土」］

施設の子どもたちは、**土を何度も掘り返されてきた子ども**です。

住む場所が変わる。関わる大人が変わる。
「この人は大丈夫かな」と思うたびに、いなくなる。

だから、枝だけ直しても、必ず戻るんです。
その子が悪いのでも、関わった大人が下手なのでもなくて、土がまだ出来ていないだけでした。

［客席へ］

……そして、これは施設の話に聞こえて、実はそうではありません。

転職を繰り返す若手。
何度言っても宿題をしない子。
指示したことしかやらない部下。

そっくりそのまま、当てはまります。

その人の土は、いま、どうなっているのか。
そこを見ないまま枝を直し続けるから、**私たちは疲れるし、相手も変わらない。**

［ゆっくり］

今日、これだけは持って帰っていただきたい一行です。

**人は、指導された分だけ育つのではありません。安心した分だけ、育ちます。**

## ３．居場所の三要素 ── 人・空間・時間（22〜33分）

［スライド６：人・空間・時間］

では、その「土」は、どうやったらつくれるのか。

私は、居場所づくりを仕事にしています。
いまは養育家庭として子どもと暮らしながら、地域で【おかえりの食卓】という食堂をひらいています。
月に一度、誰でも来ていい、ごはんを一緒に食べるだけの場所です。

その中で分かったことがあります。

**居場所は、才能でも、建物でもありません。三つの部品でできています。**

部品でできているということは、**誰でも、どこでも、組み立て直せる**ということです。
職場でも、家庭でも、地域でも。

一つずつ、お話しします。

### 一．人 ── 誰かがそこにいて、名前を覚えている。

［スライド７：人］

まず、人です。

ここで大事なのは、**何かができるから迎えられるのではない**ということです。

来たことに気づいてくれる人がいる。名前を覚えている人がいる。
それだけで、人は肩の力を抜けます。

［間］

施設にいたころ、子どもが心を開いてくれた瞬間って、実は面談の時間じゃないんです。

廊下ですれ違ったときの、
「今日、髪切った？」
これでした。

【エピソード：実際にあった小さな一言の話をここで1つ】

面談室で「最近どう？」と聞かれた子は、絶対に本当のことを言いません。
でも、**自分のことを見ている人がいる**と分かった子は、その三日後くらいに、台所にふらっと来ます。

［職場への翻訳。少しテンポを上げる］

これ、職場でそのまま使えます。

成果への評価より先に、**存在への言及**をしてください。

「おはよう」の次に、もう一言。その人自身のことを言う。
「その資料、助かった」ではなくて、「昨日遅かったでしょう、大丈夫だった？」のほうです。

これをやっている上司の1on1と、やっていない上司の1on1は、まったく別のものになります。
同じ30分でも、中身が違う。

### 二．空間 ── 靴を脱ぐように、肩の力も脱げる場所を。

［スライド８：空間］

二つめは、空間です。

居場所をつくろうとすると、多くの人が、きれいな場所を用意しようとします。
でも、必要なのは、きれいさではありませんでした。

**座っていい椅子があること。**これだけです。

子どもが走り回っても、大人がぼんやりしていても大丈夫な広さ。
何もしていない人が、居心地悪くならない場所。

［間］

食堂をひらいていて、いちばんよく分かるのは、
**人が本当のことを言うのは、向かい合ったときではなく、横に並んでいるとき**だということです。

野菜を切りながら。お皿を運びながら。
ふっと、「実はさ」が出る。

【エピソード：食卓で出た本音の話をここで1つ】

［職場へ］

会議室は、どう頑張っても「評価される場所」です。
入った瞬間に、姿勢がよくなる場所では、本音は出ません。

人が本当のことを言うのは、給湯室、移動中の車、並んで手を動かしている作業机。
**台所が、最強の面談室です。**

もし職場で一つだけ変えられるなら、場所を変えてください。
向かい合うのをやめて、横に並んでください。それだけで出てくる情報が変わります。

### 三．時間 ── 急がないこと。育つ速度を、待つこと。

［スライド９：時間］

三つめ。時間です。

これが、いちばん難しいと思います。

**一度で仲良くならなくていいんです。**

私たちは、初回で関係をつくろうとしすぎます。
初回面談でうまく話せなかった、相性が悪いのかもしれない、と。

［間］

でも、施設で見てきたのは逆でした。

**月に一度でも、通い続けられることのほうが、人を安心させます。**

【エピソード：半年ぶりに口をきいた子の話／食堂の常連になった方の話】

あれは、私が待っていたのではありません。
**ただ、いつもの場所に、いつも通りいただけ**です。
その子にとっては、「行っても、まだあの人がいる」ということ自体が情報だったんだと思います。

［職場へ。ここは少し強く］

だから私は、こう思っています。

**三か月で結果を求める育成計画は、育成ではなく、選別です。**

期限を切っていいのは、仕事の納期です。
人の変化に納期をつけると、間に合わなかった人が、全員「向いていない人」になってしまう。

［スライド10：まとめの一行。ここは板書代わりに大きく］

三つ、まとめます。

**居場所 ＝ 迎えてくれる人 ＋ 肩の力が抜ける空間 ＋ 急かされない時間。**

この三つが揃ったとき、人はやっと「ただいま」と言えます。

逆に言えば、いま人が育っていない場所は、**この三つのどれかが欠けているだけ**です。
その人の能力の問題ではありません。

## ４．迎える人が、枯れないために（33〜38分）

［スライド11：ここでトーンを変える。少し静かに］

……ここまで聞いて、しんどくなった方、いらっしゃると思います。

「結局、迎える側が頑張れという話か」と。

ここからが、今日いちばんお伝えしたいところです。

［間］

「おかえり」と言い続ける側の人は、**実はいちばん「ただいま」を言えていない人**なんです。

施設の職員もそうでした。管理職の方も、親御さんも、同じだと思います。
支援する側、育てる側に回った瞬間に、**自分の弱音の置き場がなくなる**んです。

［ゆっくり］

燃え尽きって、優しさが足りないから起きるのではありません。

**戻る場所がないまま、迎え続けるから起きます。**

私自身、そうでした。
子どものために、と思ってやっていたことが、いつの間にか、
自分が「ちゃんとやれている人」でいるための作業になっていた時期があります。

【エピソード：自分が「ただいま」を言えなかった時期の話。ここは正直に】

［スライド12：三つの提案］

だから、三つだけご提案があります。

**一つめ。役割を降りる時間を、予定に書いてください。**

「余裕ができたら休もう」は、一生来ません。
上司でもなく、親でもなく、支援者でもない時間は、**意識ではなく、予定でしか守れません。**

**二つめ。評価されない関係を、一つ持ってください。**

成果の話をしなくていい相手を、一人でいいので。
あなたが何をしたかに関係なく、あなたが来たことを喜ぶ人。
それがいない人は、無意識に、部下や子どもにその役目をやらせてしまいます。

**三つめ。できなかった日を、記録に残してください。**

うまくいった日ではなく、うまくいかなかった日のほうです。
**自分の失敗を語れる人だけが、他人の失敗を待てます。**

［間］

今日の、もうひとつの結論です。

**自分に「ただいま」を許していない人は、誰かに「おかえり」と言い続けることはできません。**

どうか、ご自分の分を、先に確保してください。

## ５．明日の「おかえり」を、一つ決める（38〜43分）

［スライド13：ワーク。配布資料の裏面を使う］

最後に、3分だけ、書く時間をください。
発表はしません。誰にも見せません。安心して書いてください。

三つ、書きます。

**一つめ。あなたが最後に「ただいま」と言えた場所は、どこですか。**
場所でも、人でも、時間でもかまいません。

［30秒待つ］

**二つめ。あなたに「おかえり」と言ってほしい人は、誰ですか。**
顔を、一人だけ思い浮かべてください。部下でも、お子さんでも、同僚でも。

［30秒待つ］

**三つめ。その人に、明日いちばんにかける一言を、書いてください。**

条件が一つだけあります。
**助言でも、指示でもないこと。**
その人が来たことに気づいた、と伝わる一言にしてください。

［1分半待つ。会場を静かに歩く］

［スライド14：共有］

……ありがとうございます。
よろしければ、隣の方と、三つめだけ、一言交換してください。30秒どうぞ。

［30秒。可能なら2〜3名に聞く］

## ６．結び（43〜45分）

［スライド15：タイトルに戻す。原稿を置いて、客席を見て話す］

私は、子どもを立派にする方法を知りません。

部下を伸ばす技術も、たぶん、ここにいらっしゃる皆さんのほうが詳しいと思います。

ただ、ひとつだけ、見てきたことがあります。

［ゆっくり］

人は、**誰かの役に立つためだけでも、何かを頑張るためだけでもなく、
「自分は、ここにいていい」と思えた場所から、勝手に育っていきます。**

勝手に、です。
こちらが育てるのではありません。

［間］

特別なことは、何も起きません。

ごはんの時間。おやすみの前の、少しの雑談。
行ってらっしゃい、と言って送り出す朝。

その積み重ねだけが、誰かの「戻ってこられる場所」になっていきます。
私が【◯年】かけて見てきたのは、本当にそれだけでした。

［間］

明日、職場の入口で。あるいは、家の玄関で。

さっき思い浮かべた一人の顔を、もう一度思い出して、言ってみてください。

［ゆっくり、はっきり］

**「おかえり。」**

帰る場所には、いつも灯りがついています。

今日は、その灯りをつける側の話をしに来ました。

ご清聴、ありがとうございました。

［礼］

## 質疑応答でよく来る質問と、答えの方向

| 質問 | 答えの軸 |
|---|---|
| 成果を出さない部下を、いつまで待てばいいのか | 待つのは変化であって、仕事の納期ではない。納期は切る、人格は切らない、を分けて話す |
| 甘やかしになりませんか | 安心と甘やかしの違いは「要求があるかどうか」。土ができた人にこそ、高い要求が届く |
| 忙しくて、そんな時間はありません | 時間ではなく順番の話。声かけの総量を増やすのではなく、最初の一言を替えるだけ |
| うちの職場では上が変わらない | 三要素のうち「人」は、役職がなくてもできる。隣の一人から始められる |
| 自分自身が「ただいま」を言える場所がない | 第4章の三つの提案に戻す。ここは正直に、自分もまだ途中だと伝える |

---

## 時間を縮めるとき、削る順番

- **30分にする**：第1章の失敗談を半分に、第4章の三つの提案を一つ（「役割を降りる時間を予定に書く」）に絞る。ワークは三つめだけ。
- **20分にする**：つかみ → 第2章の対比スライド → 三要素 → 結び。ワークは「一人の顔を思い浮かべてください」だけにして、書かせない。
- **削ってはいけない**：冒頭の「おかえり」の実話、対比スライド、三要素のまとめ一行、結びの「おかえり。」
