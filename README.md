# Bloom Terra — ホームページ

合同会社 Bloom Terra（代表 NAOMI ATSUTA / @naoon_20）のホームページ。

- `site/index.html` — 1ページ完結のホームページ（ビルド不要。ブラウザで開けばそのまま表示されます）

## 構成

ヘッダー → ヒーロー →「ただいま／おかえり」バンド → ごあいさつ → 大切にしていること（人・空間・時間）
→ 活動（3つ） → おかえりの食卓（開催概要） → お問い合わせ・会社情報 → フッター

## 記入が必要な箇所

点線の下線がついている箇所は未確定のため空欄にしてあります。

- おかえりの食卓：開催日／時間／場所／参加費
- 会社情報：所在地／メールアドレス
- 写真スロット2箇所（プロフィール写真・食卓の写真）

## デザイン

- 配色: 藍墨 `#212C3D` / 生成り `#F3F3EF` / 苔 `#46684E` / 灯 `#E4A96B`
- 書体: Zen Old Mincho（見出し）/ Zen Kaku Gothic New（本文）/ Jost（欧文ラベル）
- ライト／ダークの両テーマ対応、スマートフォン幅対応
